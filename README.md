# Portafolio de María Alejandra Ibarra Gómez

Sitio estático en español con tema tecnológico oscuro, responsive, creado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: contenido del sitio y proyectos.
- `styles.css`: diseño responsive.
- `script.js`: filtros, menú y configuración de contacto.
- `assets/favicon.svg`: icono del sitio.

## Antes de publicar
1. El correo profesional, GitHub y LinkedIn ya están configurados en `script.js`.
2. En `index.html`, añade los enlaces públicos reales de tus repositorios cuando los tengas. Las tarjetas son una estructura inicial: valida las descripciones y tecnologías contra tus proyectos reales.
3. No publiques credenciales, tokens ni información privada.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo, `portafolio-profesional`).
2. Sube todos los archivos de esta carpeta a la raíz; `index.html` debe quedar en la raíz.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
5. Espera a que GitHub publique el sitio y abre la URL que aparece en Pages.

Guía oficial: https://docs.github.com/en/pages/quickstart
